# «Пульт» — керування планшетом через Claude

Частина «Лабораторії Claude» (див. `../LAB.md`). Зроблено на прохання користувача: «пишу Claude — планшет виконує».

## Як влаштовано
- Канал команд — гілка `pult` цього (публічного) репозиторію, файл `command.json`. Надсилати: `python3 tools/pult.py`.
  Писати в гілку можуть лише ті, хто має push-доступ, тому чужі команди неможливі. Гілка не запускає збірку CI.
- Планшет (`PultService`, foreground-служба зі сповіщенням) кожні 3 с (екран увімкнено) / 6 с (вимкнено) питає git-сервер
  GitHub про вершину гілки (`ls-refs` протоколу v2, ~65 байт, без ліміту REST API). Коли коміт змінився — бере
  `raw.githubusercontent.com/<sha>/command.json` і виконує. Команди, старші за 10 хв, пропускає (поле `sent`).
- Розблокування: `WakeActivity` (showWhenLocked + turnScreenOn + requestDismissKeyguard). Працює лише для замка-свайпу.
- Відкривати застосунки з фону Android дозволяє лише з дозволом «Поверх інших застосунків» — екран підготовки просить його.
- Інтерфейс — `src/main/assets/pult.html` (у браузері без Android показує демо; `?state=off`, `?state=empty`, `?msg=…`).

## Формат команди
```json
{"id":"…","sent":"2026-11-09T08:10:00Z","say":"Розбуди й відкрий Вікно",
 "actions":[{"do":"wake"},{"do":"open","app":"ua.nebo.vikno"}]}
```
Дії: `wake` · `open` (`app`: пакет або назва з лаунчера, `extras`: рядки для Intent) · `url` · `volume` (`level` 0–100)
· `say` (`text`, синтез мовлення українською) · `show` (`text`, великий напис на екрані) · `home`
· `awake` (`minutes`, 0 — відпустити) · `wait` (`ms`).

Пакети лабораторії: ua.nebo.vikno (Вікно), ua.nebo.pisok (Пісочниця), ua.nebo.ruina (Руйнівник), ua.nebo.struny (Струни),
ua.nebo.kvartyra (Квартира), ua.nebo.widget (Небо), ua.nebo.svitanok (Світанок), ua.nebo.onovlennia (Оновлення).

## Правила
1. Java — обережно: локально SDK немає, компілює лише CI.
2. Нові дії — і в `Runner.java`, і в `tools/pult.py`, і в списку «Що вмію» на сторінці.
3. Запис у changelog.js зверху; коміт `Пульт, день N: …`.
