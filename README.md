# Небо над Україною

Android-віджет: годинник, погода, карта тривог по областях і районах, шахеди й ракети на карті.

APK збирається автоматично у вкладці Actions (артефакт Nebo-apk).

Дані: siren.pp.ua, alerts.in.ua, ubilling, NEPTUN (неофіційні дані про цілі), Open-Meteo. Межі: OCHA / geoBoundaries (CC BY 3.0 IGO). Не замінює сирену та офіційний застосунок «Повітряна тривога».

## Вікно

Окремий застосунок `vikno/` — живий пейзаж для планшета: справжнє сонце й місяць над Львовом, погода, пори року. Щоранку отримує одне покращення; див. `vikno/ROADMAP.md`, щоденник — у самому застосунку. APK: Vikno.apk у релізі.
