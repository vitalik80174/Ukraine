# «Вікно» — щоденний експеримент

Живий пейзаж для планшета. Кожного ранку Claude додає одне покращення і записує його в щоденник застосунку.

## Правила щоденного покращення
1. **Одне помітне покращення за ранок.** Краще маленьке й гарне, ніж велике й зламане.
2. Усе малюється в `src/main/assets/vikno.html` (canvas). Java-частину чіпати тільки якщо без цього ніяк (напр. звук, заставка, віджет).
3. Перевірити в headless Chromium зі параметрами `?h=<година>&m=<місяць>&wx=clear|cloudy|rain|snow|fog|storm&speed=<x>` — без помилок у консолі, подивитись скриншоти кількох сцен.
4. Додати запис **зверху** в `src/main/assets/changelog.js`: наступний `day`, сьогоднішня дата, коротка назва, 1–3 речення українською для людини (без технічних слів).
5. Відмітити зроблене в списку нижче (або дописати свою ідею). Комміт у `main` українською: `Вікно, день N: …` — після пушу Actions збирає Vikno.apk у реліз.
6. Не ламати: продуктивність (≈30 fps на планшеті), роботу без інтернету, нічне приглушення.
